# gorilla100

This is VR/AR game powered by SnapAR provided by SnapChat for the SnapChat Hackthon in NYC from May 2nd to May 3rd. We are building a functionality application with multi-player feature featuring two characters fighting while users can choose who will win before the fight starts.
